# Ikram Ul Haq Khan — Premium Angular Portfolio

A fully responsive Angular 21 portfolio redesigned around a dark luxury product aesthetic.

## Run

```bash
npm install
npm start
```

## Personalize before publishing

Search `YOUR_EMAIL_HERE` in `src/app/app.component.html` and replace it with your email. Replace the LinkedIn/GitHub placeholder anchors with your real profile URLs. Project visuals are intentionally stylized so private client data is not exposed.
